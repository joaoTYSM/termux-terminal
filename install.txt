VStermu-x — instalação no Termux
================================

Requisitos
----------
- Android com Termux instalado e acesso à internet.
- Node.js no Termux.
- Para o terminal interativo (nano, vim, top etc.), Android ARM64 e suporte do
  pacote node-pty-android-arm64.

1. Instale as ferramentas necessárias
-------------------------------------
pkg update -y
pkg install -y nodejs python make clang pkg-config git

2. Autorize o acesso ao armazenamento compartilhado
---------------------------------------------------
termux-setup-storage

Aceite a solicitação do Android. O servidor mantém os arquivos de trabalho em
$HOME e usa /storage/emulated/0/LinuxTerminal para os recursos de mídia e o
espelho de arquivos já usado pelo aplicativo.

3. Baixe o projeto
------------------
cd "$HOME"
git clone https://github.com/joaoTYSM/termux-terminal.git
cd termux-terminal

Se a pasta do projeto já existir, atualize-a em vez de cloná-la novamente:
cd "$HOME/termux-terminal"
git pull

4. Instale as dependências
--------------------------
npm install ws @xterm/xterm@6.0.0 @xterm/addon-fit@0.11.0 node-pty@npm:node-pty-android-arm64@1.1.0

O pacote node-pty é necessário para programas interativos como nano. Se a
instalação dele falhar, confira a arquitetura do dispositivo e as instruções
atuais do pacote node-pty-android-arm64.

5. Inicie o servidor
--------------------
node server.js

O Termux tentará abrir o navegador. Se isso não acontecer, visite:
http://127.0.0.1:8765

Para encerrar o servidor, volte ao Termux e pressione Ctrl+C.

Segurança e opções
------------------
- O servidor escuta somente em 127.0.0.1, neste dispositivo.
- Arquivos .env e variantes como .env.local ficam ocultos e bloqueados na
  interface por padrão. Para mostrá-los, abra Configurações > Segurança e
  visibilidade e ative “Mostrar arquivos .env”. Desativar a opção bloqueia as
  rotas do gerenciador e limpa esses arquivos das abas e dos recentes.
- O terminal do Termux continua sendo um shell completo: quem usa o próprio
  terminal ainda pode executar comandos que leem arquivos .env. A opção protege
  o gerenciador de arquivos do VStermu-x; ela não substitui permissões do
  Android nem criptografia.
- Imagem/vídeo de fundo e partículas começam desligados. O vídeo padrão só é
  carregado quando você o ativa nas configurações.
- Se precisar reinstalar/atualizar depois de um git pull, rode novamente o
  comando npm install acima antes de iniciar o servidor.
